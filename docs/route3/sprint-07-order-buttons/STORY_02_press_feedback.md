# Story 02 — Press feedback

**Sprint 07** · **UI**

Needs story 01.

## Scope

The new order buttons should feel like Navigate and Call when pressed: they sink or darken for the moment of the press, then return. No loop, no delay before the link opens.

Files: restaurant-card scss (and html only if a class is required). No `server/` edits.

## Acceptance criteria

- [ ] Pressing Order on Wolt, Order on 10bis, or Order on Mishloha shows a visible pressed state
- [ ] Releasing the press returns the button to its normal look
- [ ] The provider still opens on click
- [ ] Navigate and Call look the same as before this story

## Agents
